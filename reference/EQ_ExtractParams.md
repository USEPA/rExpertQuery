# Extract crosswalk for params and filter names for POST request for the specified query (internal function)

Extract crosswalk for params and filter names for POST request for the
specified query (internal function)

## Usage

``` r
EQ_ExtractParams(extract = NULL)
```

## Arguments

- extract:

  enter extract type. Options are: "actions", "act_docs", "assessments",
  "aus", "au_mls", "catch_corr", "sources", and "tmdl".

## Value

A df of the params for the selected extract.
