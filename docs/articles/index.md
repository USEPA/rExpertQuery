# Articles

### All vignettes

- [rExpertQuery Cybertown
  Training](https://usepa.github.io/rExpertQuery/articles/CybertownTraining.md):

  rExpertQuery is a new R package which allows users to query and
  download ATTAINS data via Expert Query web services. This vignette
  demonstrates the use of rExpertQuery functions to import common data
  profiles. Some examples of how to summarize or create visualizations
  of these data using other R packages are also be provided.

- [Getting Started With
  rExpertQuery](https://usepa.github.io/rExpertQuery/articles/GettingStartedWithrExpertQuery.md):

  An overview of rExpertQuery functions for querying and downloading
  ATTAINS data via Expert Query web services.
