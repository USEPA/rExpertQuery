# Provides allowable values for a param by leveraging ATTAINS web services.

Provides allowable values for a param by leveraging ATTAINS web
services.

## Usage

``` r
EQ_DomainValues(domain = NULL)
```

## Arguments

- domain:

  Character string. Running this function without entering a value for
  domain will return a list of all allowable domain values.

## Value

A df allowable values for the selected domain if a domain is provided.
If no domain is provided, the function returns a list of domains.
