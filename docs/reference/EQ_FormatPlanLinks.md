# Format Plan Summary Links as URLs

Format Plan Summary Links as URLs

## Usage

``` r
EQ_FormatPlanLinks(.data, url.col = "planSummaryLink")
```

## Arguments

- .data:

  Data frame to convert planSummaryLink to functional URL links for use
  in data tables.

- url.col:

  Column name containing string for formatting. Default is
  "planSummaryLink".

## Value

The .data data frame with planSummaryLink entries formatted as URL
links.
